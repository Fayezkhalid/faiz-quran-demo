# خلفية ماتريكس متحركة | Faiz Matrix Wallpaper

خلفية سطح مكتب متحركة لويندوز: مطر ماتريكس + اسمك بالبكسلات يتفكك ويتشكل من جديد + ساعة 12 ساعة + تاريخ ميلادي وهجري.

## التشغيل على ويندوز (الأفضل: Lively Wallpaper - مجاني)
1. نزّل **Lively Wallpaper** من متجر مايكروسوفت أو https://www.rocksdanister.com/lively/
2. اسحب ملف `faiz-matrix-wallpaper.zip` (أو مجلد matrix-wallpaper كامل) إلى نافذة Lively، أو: Add Wallpaper → Open.
3. اضغط على الخلفية لتفعيلها. من أيقونة التخصيص تقدر تغيّر الاسم (إنجليزي/عربي) واللون وسرعة المطر ومدة بقاء الاسم والتاريخ الهجري.
4. تأكد من Lively → Settings → Wallpaper → Input: "Mouse" (للتفاعل مع الماوس على سطح المكتب).

## التجربة بدون تثبيت
افتح `index.html` في Chrome/Edge واضغط F11. تقدر تعدّل بالرابط: `index.html?en=FAYEZ&ar=فايز&color=%2300ff66&speed=1.5&hold=12&hijri=0`

## التفاعل
- الماوس يدفع بكسلات الاسم، يضيء الشبكة، ويلوي أعمدة المطر.
- النقر يطلق موجة صدمة.
- لو الماوس ثابت 5 ثواني، يتحرك "مؤشر شبحي" عشان تبقى الخلفية حيّة.
- الاسم يتبدل بين الإنجليزي والعربي بنظام فك التشفير (Matrix decode)، مع مسح ضوئي وتشويش عشوائي كل شوي.
