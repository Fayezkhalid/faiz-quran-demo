# نغم ستوديو 🎤

تطبيق غناء (كاريوكي) احترافي يشتغل على الجوال كتطبيق ويب (PWA): تغني على موسيقى بدون صوت المغني، والتطبيق يصحح نغمتك ويضيف مؤثرات ستوديو.

## المزايا

| الميزة | التفاصيل |
|---|---|
| تصحيح النغمة (Auto-Tune) | كشف النغمة لحظياً + تصحيح للمقام، مع قوة وسرعة قابلة للتحكم (من طبيعي إلى أوتوتيون واضح) |
| مقامات عربية | ماجور/عجم، مينور، نهاوند، حجاز، كرد، **راست، بياتي، صبا بربع التون** |
| هارموني | صوت ثاني تلقائي (ثالثة/خامسة فوق، ثالثة تحت، أوكتاف تحت) متوافق مع المقام |
| مؤثرات ستوديو | EQ بأربع نطاقات، كومبرسر، دبل ستيريو، ريفيرب (غرفة/بليت/قاعة)، صدى متزامن مع سرعة الأغنية |
| إعدادات جاهزة | طبيعي، ستوديو، بوب حديث، طرب، مسرح، راديو |
| تعديل بعد التسجيل | الصوت يُحفظ خام، وتقدر تغيّر كل المؤثرات وتعيد التصدير بدون ما تغني من جديد |
| المكتبة | استيراد أي ملف صوتي، كشف تلقائي للمقام والسرعة، إزالة تقريبية لصوت المغني، مفضلة وبحث وتصنيف |
| الكلمات | صيغة LRC، أو اكتب الكلمات وزامنها بالنقر وأنت تسمع |
| الكتالوج | ملف `catalog.json` تحدّثه أنت، وتظهر الموسيقى الجديدة لكل المستخدمين |
| تقييم الأداء | نسبة دقة النغمة لكل تسجيل |
| التزامن | تعويض تأخير الجهاز تلقائياً + قياس بالنقرات + ضبط يدوي لكل تسجيل |
| بدون إنترنت | يشتغل أوفلاين بعد أول فتح، وكل البيانات تبقى على الجهاز |

## التشغيل

التطبيق ملفات ثابتة (HTML/JS) بدون سيرفر. يحتاج **HTTPS** عشان المايك يشتغل على الجوال.

- محلياً: `python3 -m http.server` داخل مجلد `karaoke` ثم افتح `http://localhost:8000`
- على الجوال: انشره على GitHub Pages (أو أي استضافة HTTPS)، افتح الرابط، ثم «إضافة إلى الشاشة الرئيسية».

## إضافة موسيقى للكتالوج

عدّل `catalog.json`:

```json
{
  "updated": "2026-11-01",
  "tracks": [
    {
      "id": "unique-id-1",
      "title": "اسم الأغنية",
      "artist": "الفنان",
      "genre": "خليجي",
      "url": "music/song1.mp3",
      "lrcUrl": "music/song1.lrc",
      "key": "D",
      "scale": "hijaz",
      "bpm": 92,
      "removeVocals": false
    }
  ]
}
```

- `url` نسبي للكتالوج أو رابط كامل (لازم يسمح بالتحميل CORS).
- `key` / `scale` / `bpm` اختيارية؛ لو ما حطيتها التطبيق يكتشفها.
- السلالم المتاحة: `major, minor, nahawand, hijaz, kurd, rast, bayati, saba, pentatonic, chromatic`.

> ⚠️ **الحقوق:** الموسيقى التجريبية الثلاث مولّدة داخل التطبيق ومن تأليفنا. أي موسيقى تضيفها للكتالوج العام لازم تكون مرخصة (من إنتاجك، أو مكتبات بترخيص تجاري، أو اتفاق مع المنتج). الاستيراد الشخصي من جوالك للاستخدام الخاص.

## هيكل الكود

```
karaoke/
├─ index.html, styles.css      الواجهة
├─ js/app.js                   منطق الشاشات
├─ js/engine.js                سلسلة المؤثرات، التشغيل، التسجيل، الميكساج
├─ js/worklets.js              معالجة الصوت اللحظية: كشف وتصحيح النغمة، الهارموني، التسجيل
├─ js/analysis.js              كشف المقام والسرعة، إزالة صوت المغني
├─ js/demos.js                 الموسيقى التجريبية المولدة
├─ js/music.js                 المقامات، الإعدادات الجاهزة، الكلمات
└─ sw.js, manifest.webmanifest تطبيق قابل للتثبيت ويشتغل أوفلاين
```
