# سكينة · تطبيق أم فايز 🌸

تطبيق ويب يشتغل على الجوال كتطبيق (PWA)، هدية من فايز لأمه.

## المزايا

| القسم | التفاصيل |
|---|---|
| الرئيسية | ترحيب ودعاء متغيّر كل مرة باسم «أم فايز»، ساعة عقارب مزخرفة (المسيها تصير رقمية)، سماء حيّة تتغير مع وقت اليوم، التاريخ الهجري (أم القرى) والميلادي، مواقيت الصلاة لبريدة مع عدّاد الأذان القادم، عدّاد رمضان (وفي رمضان: عدّاد الإفطار والإمساك)، تذكيرات الجمعة والاثنين والخميس والأيام البيض وعرفة وعاشوراء، وآية اليوم |
| الأذكار | الصباح والمساء (تختار تلقائياً حسب الوقت) + بعد الصلاة + النوم + الاستيقاظ. اضغطي على الذكر فينقص العدد، ويتحفظ التقدّم لليوم، مع الفضل والمصدر |
| السبحة | سبحة دائرية من ٣٣ حبة تدور مع كل ضغطة، أهداف ٣٣/١٠٠/١٠٠٠/مفتوح، ١١ ذكر جاهز + ذكر خاص، إحصائيات اليوم وآخر ٧ أيام، صوت واهتزاز، والشاشة تبقى مضاءة |
| التفسير | ابحثي بالكتابة أو اللصق أو **بالصوت**، أو تصفّحي بالسورة والآية. التفسير الميسّر كامل داخل التطبيق، مع الاستماع للآية بصوت العفاسي |
| الأصوات | ٦ أصوات طبيعة مولّدة داخل التطبيق بدون إنترنت (عصافير، جدول، نهر، مطر، موج، ليل) + بث مباشر لأذكار الصباح والمساء، إذاعة القرآن، الرقية، و١٠ قرّاء |
| القبلة | بوصلة باتجاه القبلة من بريدة (٢١٩°) |
| رسالة من فايز | بطاقة في الرئيسية على شكل ظرف، تضغط عليها فينفتح ويشتغل صوتك. تظهر كلمة «جديدة» لكل رسالة ما سمعتها |
| الإعدادات | حجم الخط (من ١٦ إلى ٣٤) مع أزرار أ+ و أ- داخل صفحات الأذكار والتفسير، خط عريض، ١٠ خطوط عربية، ٥ ثيمات مريحة للعين (وردي، لافندر، نعناعي، لؤلؤي، ليلي)، وضع ليلي تلقائي بعد المغرب، أرقام عربية، تنبيهات الأذان والأذكار، وتصدير المواقيت للتقويم |

## التثبيت على جوال الوالدة

1. افتح الرابط: `https://fayezkhalid.github.io/faiz-quran-demo/um-fayez/`
2. **آيفون:** من Safari اضغط زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
   **أندرويد:** من Chrome اضغط ⋮ ← «تثبيت التطبيق».
3. افتحه من الأيقونة، ومن الإعدادات فعّل التنبيهات واضغط «أضيفي التنبيهات للتقويم».

## إضافة رسالة صوتية من فايز

1. افتح صفحة التسجيل من جوالك: `https://fayezkhalid.github.io/faiz-quran-demo/um-fayez/record.html`
2. سجّل الرسالة واضغط «حفظ / مشاركة الملف».
3. أرسل الملف لـ Claude يضيفه، أو ارفعه بنفسك في مجلد `um-fayez/media/` وأضف سطره في `media/messages.json`:

```json
{
  "messages": [
    { "file": "media/fayez-20261028.m4a", "title": "رسالة لأمي الغالية", "date": "2026-10-28" }
  ]
}
```

تقدر تضيف رسائل كثيرة (عيد، رمضان، جمعة…)، والأحدث يطلع أول. البطاقة ما تظهر في الرئيسية إلا إذا فيه رسالة.

## ملاحظات

- يحتاج إنترنت أول مرة فقط، بعدها الأذكار والسبحة والمواقيت والتفسير تشتغل بدونه. البث المباشر والاستماع للآيات والتسجيل بالصوت تحتاج إنترنت.
- التنبيهات داخل التطبيق تشتغل والتطبيق مفتوح أو في الخلفية. التنبيه المضمون مع الجوال المقفل يكون عن طريق ملف التقويم (٣٠ يوم، يُجدّد شهرياً).

## المصادر

- الأذكار: «حصن المسلم» (hisnmuslim.com).

- مواقيت الصلاة: مكتبة [adhan](https://github.com/batoulapps/adhan-js) (MIT) بطريقة أم القرى.
- البث: mp3quran.net. تلاوة الآيات: cdn.islamic.network.
