# Claude يتصل على جوالك إذا خلص الشغل

## على الجوال
1. سوّ حسابين مجانيين من https://subscribe.linphone.org وفعّل كل واحد من الإيميل:
   - حساب للكمبيوتر، مثل `abokhalid-claude`
   - حساب للجوال، مثل `abokhalid-phone`
2. نزّل تطبيق **Linphone** وسجّل دخول بحساب **الجوال**، واسمح بالإشعارات.
3. أندرويد: الإعدادات ← التطبيقات ← Linphone ← البطارية ← **غير مقيّد**. (سامسونج: وتأكد إنه مو في التطبيقات النائمة.)

## على الكمبيوتر (ويندوز)
1. افتح مجلد `.claude/skills/call-me` داخل هذا المشروع.
2. (اختياري) حط تسجيلاتك بصوتك داخل نفس المجلد باسم `voice.mp3` (نجاح) و `wrong.mp3` (مشكلة). لو ما حطيت، يتسوّى لك صوت سعودي تلقائيًا.
3. افتح PowerShell داخل المجلد وشغّل:
   ```
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
   بيسألك عن اسم حساب الكمبيوتر، اسم حساب الجوال، وكلمة سر حساب الكمبيوتر.
4. جرّب:
   ```
   cd "$env:USERPROFILE\.claude\skills\call-me"
   python call_me.py
   ```
   جوالك يرن باسم "Claude"، رد وبتسمع الرسالة.

## الاستخدام
افتح جلسة Claude Code جديدة واكتب مع طلبك: **"اتصل علي إذا خلصت"**.
أول مرة يطلب إذن تشغيل السكربت، اختر الخيار اللي يمنع السؤال مرة ثانية.

## تنبيه أمان
`sip-password.txt` نص مكشوف. استخدم كلمة سر خاصة لهذا الحساب بس، ولا تشارك مجلد `call-me` مع أحد.
