# دليل السكيلز بالعربي

كل سكيل: وش تسوي بالضبط، ومتى تستخدمها.

## حزمة Replica (استنساخ التطبيقات) — بالترتيب

| السكيل | وش تسوي بالضبط |
|---|---|
| `/replica-recon` | **الاستطلاع (أول خطوة):** تحلل أي تطبيق من صفحاته العامة ولقطات الشاشة ووصف المتجر وتطلع خريطة: الشاشات، التدفقات، المكوّنات، نموذج البيانات، ومصفوفة الميزات. |
| `/replica-architect` | **الهندسة:** تختار التقنيات، تكتب مخطط قاعدة البيانات (SQL حقيقي مع الفهارس والصلاحيات)، تسرد كل المسارات (routes)، وترتب البناء بحيث تبدأ بشريحة رأسية رفيعة. |
| `/replica-design` | **التصميم:** تبني نظام التصميم (ألوان، خطوط، مسافات، ظلال، مكوّنات بحالاتها) كـ tokens ومواصفات، بأصول أصلية بدل شعارات وخطوط الأصل، مع فاحص تباين WCAG. |
| `/replica-build` | **البناء:** تبني الشاشات واحدة واحدة: الهيكل أولًا، ثم التدفق الأساسي، ثم باقي الشاشات بكل حالاتها، وتشطب الميزات من المصفوفة. كل سطر يُكتب من جديد. |
| `/replica-backend` | **الخلفية:** تسجيل الدخول، قاعدة البيانات والمايقريشنز، الدفع بـ Stripe، البريد، المهام الخلفية، التكاملات عبر الـ APIs الرسمية فقط، وقائمة فحص أمني. |
| `/replica-test` | **الاختبار:** تولّد خطة اختبار من التدفقات، تكتب اختبارات Playwright، تنقر على كل شي في المتصفح، وتكتب تقارير أخطاء بصيغة ثابتة (الخطورة، الخطوات، الدليل). |
| `/replica-diff` | **المقارنة:** تقيس نسبة تطابق ميزات نسختك مع الأصل (موزونة: أساسي/مهم/إضافي) وتعطيك الناقص بترتيب البناء، وتقارن لقطات الشاشات بدون احتساب الألوان. |
| `/replica-entrepreneur` | **ريادة الأعمال:** تقرأ مراجعات مستخدمي التطبيق الأصلي (App Store، Google Play، Reddit…) وتطلع وش يكرهون وش الناقص، وخطة تحسين وزاوية تسويق. الاقتباسات حقيقية وبروابط. |
| `/replica-brand` | **الهوية:** تقترح أسماء مع فحص العلامة التجارية والدومين والمتاجر، لوحة ألوان بتباين مفحوص، وصف شعار، دليل نبرة، وأداة تفتش عن أي بقايا من الأصل في الكود. |
| `/replica-launch` | **الإطلاق:** صفحة الهبوط، التسعير مقابل الأصل وشكاوى مستخدميه، وقوائم App Store وGoogle Play مفحوصة على حدود المتاجر، وخطة الإطلاق. |
| `/replica-deploy` | **النشر:** فحص ما قبل النشر، قاعدة الإنتاج والمتغيرات، الاستضافة، DNS للدومين والبريد، Stripe الحقيقي، OAuth، المراقبة، وبناء الجوال لـ TestFlight وPlay. |

## سكيلز الملفات والمكاتب

| السكيل | وش تسوي بالضبط |
|---|---|
| `pdf` | قراءة PDF واستخراج النص والجداول، دمج وتقسيم، تدوير، علامات مائية، إنشاء PDF، تعبئة النماذج، تشفير، استخراج صور، OCR. |
| `docx` | إنشاء وقراءة وتعديل ملفات Word، تعديلات متتبَّعة وتعليقات، استبدال نصوص وصور. |
| `pptx` | إنشاء وتعديل عروض PowerPoint، قوالب، ملاحظات المتحدث، دمج وتقسيم. |
| `xlsx` | فتح وتعديل وإصلاح جداول Excel/CSV، معادلات وتنسيق ورسوم، تنظيف بيانات فوضوية. |
| `docs` | مستندات قابلة للمشاركة والتعليق (تقرير، مقترح، سيرة ذاتية، عقد…) وتصدّر لـ Word/PDF/Markdown/Google Docs. |
| `google-workspace` | إنشاء وتعديل ملفات Google (Docs, Sheets, Slides) في Drive. |
| `canvas-design` | بوسترات ولوحات وتصاميم ثابتة PNG/PDF بفلسفة تصميم أصلية. |
| `dataviz` | أي رسم بياني أو لوحة مؤشرات: ألوان، تخطيط، تلميحات، وتسهيلات الوصول. |

## سكيلز المتصفح والجهاز

| السكيل | وش تسوي بالضبط |
|---|---|
| `built-in-browser` | دليل استخدام المتصفح المدمج في تطبيق Claude. |
| `chrome-browser` | دليل استخدام إضافة Claude in Chrome في متصفحك الحقيقي. |
| `computer-use` | التحكم بتطبيقات جهازك عبر لقطات الشاشة والنقر والكتابة. |

## سكيلز الكتابة والبحث والمنتجات

| السكيل | وش تسوي بالضبط |
|---|---|
| `deep-research` | بحث عميق متعدد المصادر وتقرير متكامل. |
| `humanize-writing` | يشيل أنماط الكتابة الآلية من أي نص. |
| `import-memory` | ينقل ذاكرتك من مساعد ذكاء اصطناعي آخر إلى Claude. |
| `morning` | الموجز الصباحي كصفحة HTML أو كمهمة متكررة. |
| `artifact-design` | إرشادات تصميم صفحات الـ Artifact قبل كتابتها. |
| `artifact-diagramming` | رسم المخططات بـ SVG داخل الـ Artifact. |
| `artifact-capabilities` | قدرات الصفحة وقت التشغيل: حفظ الحالة، قاعدة بيانات مشتركة، رفع ملفات، سؤال Claude من داخل الصفحة. |

## سكيلز التطوير والأدوات

| السكيل | وش تسوي بالضبط |
|---|---|
| `/init` | ينشئ ملف CLAUDE.md يوثّق المشروع. |
| `/code-review` | يراجع التعديلات أو PR ويطلع أخطاء منطقية، بمستويات جهد من low إلى max. |
| `/simplify` | يراجع الكود المعدّل ويبسّطه ويشيل التكرار، بدون بحث عن أخطاء. |
| `/security-review` | مراجعة أمنية كاملة للتعديلات في الفرع الحالي. |
| `/run` | يشغّل التطبيق ويتأكد أن التعديل يشتغل فعليًا. |
| `/loop` | يكرر أمر أو برومبت كل فترة محددة (أو بإيقاع ذاتي). |
| `/update-config` | يعدّل settings.json: صلاحيات، متغيرات بيئة، هوكس. |
| `/fewer-permission-prompts` | يحلل جلساتك السابقة ويضيف قائمة سماح تقلل طلبات الصلاحيات. |
| `/keybindings-help` | تخصيص اختصارات لوحة المفاتيح. |
| `/plugin-authoring` | صنع mod يغيّر واجهة Claude أو سلوكه. |
| `/claude-api` | مرجع Claude API وSDK: النماذج والأسعار والـ caching وtool use. |
| `/skill-creator` | إنشاء وتحسين وقياس السكيلز. |
| `session-start-hook` | إنشاء SessionStart hook يجهّز مشروعك في الجلسات السحابية. |
