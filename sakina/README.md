# سكينة 🌿

أذكار الصباح والمساء، سبحة، تفسير القرآن، ومواقيت الصلاة. مجاني وبدون إعلانات.

**صدقة جارية، لا تنسونا ووالدينا من صالح دعائكم.**

تطبيق ويب (PWA) يتثبّت على الجوال: من Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»، أو من Chrome ← ⋮ ← «تثبيت التطبيق».

## المزايا
- أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ (حصن المسلم) مع عدّاد بالضغط.
- سبحة دوّارة بأهداف وإحصائيات.
- تفسير القرآن (التفسير الميسّر) بالبحث كتابةً أو لصقاً أو بالصوت، ويشتغل بدون إنترنت.
- مواقيت الصلاة لأي مدينة في المملكة أو حسب الموقع (أم القرى داخل المملكة، ورابطة العالم الإسلامي خارجها)، مع عدّاد الأذان القادم وعدّاد رمضان والتاريخ الهجري.
- أصوات طبيعة بدون إنترنت، وبث مباشر للأذكار والتلاوات.
- حجم الخط، ١٠ خطوط عربية، ٥ ألوان، ووضع ليلي.
- بوصلة القبلة وتنبيهات الأذان والأذكار.

## المصادر
- الأذكار: «حصن المسلم».
- نص القرآن والتفسير الميسّر: مجمع الملك فهد لطباعة المصحف الشريف، عبر alquran.cloud.
- مواقيت الصلاة: مكتبة adhan (MIT).
- البث: mp3quran.net. تلاوة الآيات: cdn.islamic.network.
