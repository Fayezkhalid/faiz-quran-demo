# بيت فايز HQ

عمارة 3D فيها وكلاء بيتك: المدير العام، المالي، الإيميلات، الطابعات (Bambu Lab A2L Combo)، المصمم، مدير البيت، منسق العائلة، المرشد الأكاديمي، ووكيل الواتساب.

- **تجريبي:** افتح `index.html` أو رابط الـ Artifact. كل شي محاكاة.
- **لايف:** شغّل الجسر على كمبيوتر البيت. الصفحة تتصل بالطابعة وترسل لك واتساب وتحفظ المصاريف وتقدم الماجستير.

## التشغيل لايف (ويندوز، مرة وحدة)

1. ثبّت Node.js:
   ```
   winget install OpenJS.NodeJS.LTS
   ```
2. افتح PowerShell داخل مجلد `fayez-home-hq\bridge` وشغّل:
   ```
   npm install
   copy .env.example .env
   notepad .env
   ```
3. عبّ ملف `.env`:
   - **الطابعة:** من شاشة الـ A2L: الإعدادات ← الشبكة. خذ **IP** و**Access Code**، والرقم التسلسلي (Serial) من الإعدادات ← الجهاز أو من Bambu Studio.
     - إذا ما اتصلت: فعّل **LAN Only** و**Developer Mode** من إعدادات الطابعة (التحديثات الجديدة تمنع البرامج الخارجية بدونها).
   - **الواتساب (CallMeBot، مجاني):**
     1. افتح https://www.callmebot.com/blog/free-api-whatsapp-messages/ واحفظ رقم CallMeBot المكتوب هناك في جوالك (الرقم يتغير أحياناً، فخذه من الموقع).
     2. أرسل له على الواتساب: `I allow callmebot to send me messages`
     3. يرد عليك بـ **apikey**. حطه في `CALLMEBOT_APIKEY`، ورقمك في `CALLMEBOT_PHONE` (مثل 9665XXXXXXXX).
   - **الماجستير:** `MASTERS_REMINDER_TIME=20:00` وقت التذكير اليومي.
4. شغّل:
   ```
   npm start
   ```
   وافتح **http://localhost:8787**. فوق بيطلع لك **LIVE** باللون الأخضر.

تجربة بدون الطابعة: `npm run demo` (طابعة وهمية تطبع كل 3 دقائق).

## وش اللي صار لايف

| الخدمة | لايف؟ | كيف |
|---|---|---|
| الطابعة A2L | ✅ | تقدم الطباعة، الطبقات، الحرارة، إيقاف مؤقت/كمل |
| الواتساب | ✅ | بداية الطباعة، خلصت، علقت، الفواتير، الماجستير، تذكير يومي |
| المالية | ✅ | كل فاتورة تكتبها تنحفظ في `data/finance.json` وتتصفر كل شهر |
| الماجستير (MBA – IBA London) | ✅ | ٨ محاور × ٧ محاضرات، الاختبار النهائي والواجب، كم باقي، تذكير واتساب يومي (التقدم تسجله أنت: "خلصت المحاضرة") |
| الإيميلات | ❌ للحين | يحتاج ربط Gmail (خطوة جاية) |

## ملاحظات أمان
- `.env` فيه كلمة سر الطابعة ومفتاح الواتساب. لا ترفعه ولا ترسله لأحد (محمي بـ `.gitignore`).
- الجسر يشتغل على الكمبيوتر بس (`HOST=127.0.0.1`). إذا تبي تفتحه من جوالك في البيت حط `HOST=0.0.0.0`، وانتبه إن أي أحد على شبكة البيت يقدر يفتحه.
- رسائل الواتساب تمر عن طريق خدمة CallMeBot الخارجية.
